# Ontology and fixed-D external error audit

Slurm job `12708396` completed on `cpu203` in 36 seconds with four CPUs and
16 GB.  It streamed the existing SF5 windows and RepeatMasker outputs and
read the saved D probability arrays.  No model was loaded, no inference or
training was run, and the frozen threshold (`0.42330056285498807`), four
regions, and cached probabilities were unchanged.

## What the SF5 audit establishes

The recorded six-ID label map is exactly
`0 BG`, `1 SINE`, `2 LINE`, `3 LTR`, `4 DNA`, and `5 Unknown`.  The materialised
train, validation, and test files match their metadata class counts and
species window counts, and all three splits use only these six IDs. These are
the complete materialized-data denominators, not the legacy scored prefix:

| split | all six IDs (bp) | BG (bp) | main4 (bp) | Unknown (bp) |
|---|---:|---:|---:|---:|
| train | 22,118,400 | 13,301,627 | 8,592,510 | 224,263 |
| val | 5,898,240 | 4,532,665 | 1,311,947 | 53,628 |
| test | 8,847,360 | 5,232,207 | 3,523,237 | 91,916 |

The pure mapper probe passed for all tested classes.  `RC`, `Retroposon`, and
`PLE` are mapped to the single `Unknown` ID; ambiguous and unrecognised
classes also map there.  No tested known-other-TE class is mapped to `BG`.
However, the window builder starts every window as `BG`, so an annotation
omission is indistinguishable from true background after encoding.  The
encoded six-ID files also cannot separate known-other TE from an ambiguous or
truly unclassified record.  The external D contract used below is different:
it treats `RC` and `Retroposon` as strict TE positives.  SF5 `Unknown` scores
therefore cannot be interpreted as a single biological class or compared
directly with that external positive bucket.

The legacy held-out rows retain the observed values: the base-pretrained
model has `Unknown` recall `0.3886`, Unknown F1 `0.5020`, all-six macro-F1
`0.8146`, and main4 conditional macro-F1 `0.8644`; the binary-H0 row has
Unknown recall `0.0426`, Unknown F1 `0.0708`, all-six macro-F1 `0.7410`, and
main4 conditional macro-F1 `0.8633`.  These are valid legacy contract
metrics, but their Unknown component is not evidence that a fraction of
manually unannotated elements was recovered.  The historical chrX 90-row
diagnostic has no model predictions and is not a population estimate.

**Subsequent scored-population audit:** Slurm `12708568` reconstructed the
exact class-support counts of both legacy score rows. The loader takes the
first `max_eval_samples=1200` records in file order. The actual test therefore
contained mouse 360, zebrafish 360, chicken 360 and western-clawed frog 120
windows, totalling 4,915,200 labelled bases and 16,961 Unknown bases. It did
not score fruit fly or C. elegans. The validation prefix contained 240 windows
from each of the first five species and no C. elegans. This is a real
evaluation-coverage limitation: matching the full dataset metadata does not
establish that the reported metric covered all six species. The historical
numbers remain exact for the population actually scored. A balanced replay
must declare species quotas explicitly and retain its own population record.
[Exact prefix evidence](run-12708396/scored-prefix-12708568.json)

The inspected nonsealed SF5 bundle exposes the encoded windows, checkpoints,
and aggregate score table but no per-position held-out prediction track that
would support a new raw ontology confusion matrix.  This audit therefore
does not reconstruct an SF5 confusion matrix from invented outputs: it reports
the exact label/denominator audit and the published aggregate rows.  The
actual saved-probability/error stratification is the separate fixed-D analysis
in Part B.

## Fixed-D error strata

The primary row-level positive bucket is `known_te`, using the existing D
classes `LINE/SINE/LTR/DNA/RC/Retroposon`.  Unknown/ambiguous and hard
non-TE rows remain in the denominator audit, while unlabelled sequence is
never treated as a negative.  Row sums retain all RepeatMasker records; the
separate union numbers avoid double counting overlapping records.  The
metrics are recovery of comparator-labelled callable bases, not independent
accuracy or biological insertion recall.

| comparator | raw rows | panel rows | known-TE union bp | Unknown/ambiguous union bp | hard non-TE union bp | mean-arm known-TE recall |
|---|---:|---:|---:|---:|---:|---:|
| sea urchin, Dfam 3.9 uncurated | 10,021 | 10,021 | 844,932 | 1,239,687 | 133,506 | 0.4242 |
| platypus, Label-A | 4,973,007 | 10,811 | 1,483,825 | 2,345 | 56,638 | 0.9619 |

For sea urchin, forward/RC/mean/phase-mean union recall was respectively
`0.4289/0.4189/0.4242/0.4240`.  The main class pattern for the forward arm
was LINE `0.5063` (1,532 rows), SINE `0.4405` (680), LTR `0.5133` (187), DNA
`0.2354` (853), RC `0.3473` (68), and Retroposon `0.0196` (51).  By clipped
record length, recall was `0.2051` for `<80 bp`, `0.3312` for `80–499 bp`,
`0.4676` for `500–999 bp`, and `0.5607` for `>=1000 bp`.  By RepeatMasker
divergence, it was `0.5707` for `<5%`, `0.4135` for `5–15%`, `0.3298` for
`15–30%`, and `0.7491` for `>=30%`.  The nonmonotonic divergence pattern is
not a standalone biological explanation because class and length are mixed
within these strata.  The alternate Unknown/ambiguous union had only `0.1619`
forward recovery and the hard non-TE union `0.0461`; these are comparator
overlap diagnostics, not precision.

For platypus, forward/RC/mean/phase-mean known-TE union recall was
`0.9593/0.9595/0.9619/0.9607`.  Forward recall was LINE `0.9524` (3,946
rows), SINE `0.9848` (5,446), DNA `0.1845` (103), and LTR `0.0000` (10); the
small LTR stratum is too small for a family-wide claim.  Length strata were
`0.9573/<80`, `0.9573/80–499`, `0.9733/500–999`, and `0.9836/>=1000`.
Divergence strata were `0.9508/<5%`, `0.9808/5–15%`, `0.9702/15–30%`, and
`0.9236/>=30%`.  The Unknown/ambiguous union recovered `0.0149` and hard
non-TE `0.3314` in the forward arm.

These two panels do not support the sentence “vertebrates generalise well.”
They support only a fixed-panel comparator observation: this platypus panel
has high agreement with its sparse Label-A known-TE records, while the
sea-urchin uncurated-library panel has materially lower recovery.  The sea
urchin library is a sensitivity comparator rather than independent truth, and
the platypus Label-A output is also sparse.  The result justifies a bounded
development hypothesis for a species/domain adapter or gated expert, with
the shared model held as the control; it does not demonstrate that MoE will
solve the failure.  Any such follow-up must use held-out fixed regions,
separate calibration data, and the same threshold-selection rule.

## Label and claim repair

The minimal repair is hierarchical supervision and reporting while retaining
the six-ID legacy output for comparability:

1. keep the existing binary material endpoint and main4 heads;
2. split TE positives into main4 and `known_other_TE` (including RC,
   Retroposon, and PLE where the annotation supports them);
3. retain `ambiguous` and `true_unclassified` as explicit unresolved/abstain
   states rather than a biological `Unknown` class; and
4. report `nonTE` separately, with raw class/family provenance and an
   annotation-coverage denominator.

This permits a future family or SVA claim only when the model emits that
family label and the evaluation annotation independently supports it.  The
current model has no independent SVA output, so no SVA accuracy is reported.
