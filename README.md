# ab-initio-TE

基于基因组序列的转座子注释研究项目。研究目标和推进顺序由用户与 Agent 在对话中确定；协作规则见 `AGENTS.md`。

## 项目资料

- `docs/`：研究计划、实验协议、决策和结果记录。按当前任务读取相关内容。
- `configs/`、`scripts/experiments/`、`sbatch/`：实验配置、实现和集群提交脚本。
- `reports/`、`outputs/`、`runs/`：指标、运行产物和模型；保留历史与冻结结果。
- `data/`、`software_outputs/`、`refs/`：数据、工具结果与参考资料。

2026-09-08 已退役 Auto Research 自动目标、第三方评阅和 hook 流程。历史资料保留作为证据，不再强制设置 goal JSON 或执行三方评阅。数据隔离、冻结协议、资源预算及必要的科学核验不变。
