2026-10-02（Asia/Bangkok）；原始作业与记账时间统一用 UTC。

六臂均完成完整原生 ETP，固定评分、旧面板复核和 compact 结果同步进入收束。**D 的下游效果依赖物种：鸡主域 F1 低于完整 RM2 和 RED；鱼主域相对两者小幅提高。** 这支持有限、按物种报告的应用价值，不建立普遍优于传统掩码、未见物种泛化或自主 TE/宿主功能选择性。

## 冻结比较和验证

沿用 [2026-09-25 协议](../../docs/experiments/BRAKER-MASK-UTILITY-20260925.md) 和固定 input manifest。鸡/鱼均参与 D 微调；主域排除其 TRAIN/CAL 整条染色体和旧用途 halo，分母在目标预测前固定为 6,588 / 14,576 loci。域不是全项目 sealed 独立测试；BRAKER 仍在全基因组自训练。同物种三臂的短读长 BAM 与剔除鸡/鱼 taxid 的 OrthoDB12 蛋白参数逐项一致，原命令没有 skipOptimize 或样例 gm_max_intergenic 参数。

六个 status 均为 PREDICTION_READY，原生日志都有 BRAKER RUN FINISHED，最终 GTF 非空且已由原生包装程序逐行解析。固定评分作业鸡 13323815、鱼 13323816 均 COMPLETED/0:0，分别 106 / 133 秒；终态汇总及旧面板作业 13323909 完成，45秒。新的三臂评分中 D/RM2 的指标、逐染色体计数、10,000次 seed42 bootstrap、gross gains/losses，以及鱼全部长读长类别/染色体结果，均与既有两臂记录完全重放一致。各域 TP+FN 与冻结分母一致、逐染色体总数相符；旧面板原分母仍为鸡1,064 / 鱼984。

远程完整评分保留在冻结 evaluation 目录下的 `score-D-RM2_FULL-RED_FULL-primary.json` 与 `score-D-RM2_FULL-RED_FULL-full.json`；鱼使用成功的 `zebrafish-r2`。原单臂/两臂结果不覆盖，完整GTF和大评分JSON留在Baobab。[鸡 compact 证据](chicken-three-arm-score-summary.json)、[鱼 compact 证据](zebrafish-three-arm-score-summary.json) 保留全部逐染色体结果、gross gain/loss IDs 和全部源类别。
