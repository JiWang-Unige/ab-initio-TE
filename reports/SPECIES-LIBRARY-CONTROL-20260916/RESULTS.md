# 同版本参考库扩充：FP支持增加，但新暴露的漏检更多

2026-09-16。固定协议的三物种、六个RepeatMasker cell已完成；score12743581与重放12743579的实际结果已取回，独立compact复核通过。**本项有限诊断结束，不追加训练或搜索参考库。**

同一输入、模型、校准、阈值和注释引擎下，加入同版本Dfam未人工整理条目，确实让部分相对curated参考的FP获得新的TE参考支持；但猪和鸡新增阳性大部分落在模型预测阴性上，召回与F1大幅下降。这是参考知识条件改变错误计数的直接证据。它不能证明新增命中都是真实TE，也不能证明斑马鱼的全基因组注释更完整。

## 固定比较与结果

每物种500个原DEV窗口；8192-bp中心，加两侧各4096 bp，所有native cell实际输入均为500序列、8,192,000 bp。只评价原callable中心。共享D的NTv2-500M checkpoint、seed42、CAL参数和阈值0.42330056285498807未改变。六物种均参与过任务微调，因此这是内部DEV诊断。

| 物种 | 原历史F1 | 新curated F1 | + uncurated F1 | 新curated → 扩库 precision | 新curated → 扩库 recall |
|---|---:|---:|---:|---:|---:|
| 斑马鱼 | 0.927836 | 0.927805 | 0.927805 | 0.929745 → 0.929745 | 0.925874 → 0.925874 |
| 猪 | 0.893138 | 0.857443 | 0.648572 | 0.815677 → 0.869041 | 0.903718 → 0.517329 |
| 鸡 | 0.831720 | 0.827195 | 0.539633 | 0.846994 → 0.970830 | 0.808300 → 0.373668 |

**只能用两列新注释之间的差异归因于本次库条件。** 历史注释使用`-species`多阶段流程；新注释使用显式`-lib`及统一halo，历史→新curated还包含调用方式/上下文变化。猪的这个差异尤其明显，不可将历史F1直接当作受控扩库实验的基线。原分数和标签全部保留。

库条目为斑马鱼1966→1966、猪784→3831、鸡218→395；curated序列是不变子集。斑马鱼两库完全相同，严格TE位置也相同，是零增量对照，不能用零变化证明注释已经完备。

## 新增支持与新漏检必须一起报告

下表的“新增”均指**新curated→新combined**，不是历史标签→combined。计数是bp，不是独立insertion、family或候选数。

| 物种 | 新增阳性且模型阳性 a | 新增阳性且模型阴性 b | 新增阳性检出率 a/(a+b) | 丢失原curated阳性：模型阳性 / 阴性 |
|---|---:|---:|---:|---:|
| 斑马鱼 | 0 | 0 | 不适用 | 0 / 0 |
| 猪 | 59,990 | 801,514 | 6.96% | 923 / 238 |
| 鸡 | 19,053 | 218,855 | 8.01% | 68 / 176 |

猪和鸡分别有29.40%和81.23%的新curated参考FP获得扩库支持，但这不是独立生物学确认率，也不是原历史FP的确认率。扩库还通过注释竞争丢失少量原阳性；因此实际转换是`TP_plus = TP_curated + a - lost_predicted_positive`及`FN_plus = FN_curated + b - lost_predicted_negative`。完整四格计数、加减转换与每窗口求和均已复核。

新Unknown-only参考覆盖为：斑马鱼147→147 bp，猪48→3621 bp，鸡60→3725 bp。这些位置没有从原callable分母中事后删去。严格TE保持LINE/SINE/LTR/DNA/RC/Retroposon定义；混合类别用union计数，完整类别成员转换见原JSON。

原历史标签的类别构成也很不均衡：鸡152,412/157,905阳性bp属于exclusive LINE，LTR只有57 bp；猪与斑马鱼的exclusive LINE recall相近（0.922438与0.923935），但DNA分别为0.722171与0.926479。鸡DNA recall为0.118629（4,611 bp）。这些是不同组成/暴露条件下的描述性结果，不是控制家族、序列难度后的因果比较。零支持类别的recall在JSON为null、TSV为NA，稀少支持不得用于稳健性主张。[完整类别表](exclusive_class_recall.tsv)

## 对用户假设及论文主张的判断

1. **可写正文：** 同版本库条件影响FP与FN的可见范围；扩大参考知识后，precision上升与recall下降可以同时发生。只寻找“FP变TP”会遗漏更大的新增FN。本次实验提供一个受控的、保留全部转换的实例。
2. **不能写成：** 斑马鱼因为模式动物身份而有更完整注释；猪/鸡低F1主要由错误FP造成；扩库F1是纠正后的真实精度；所有新增未整理条目都可信。三物种没有形成注释完整度的独立金标准。
3. **不追加本轮候选审查：** 当前结果足以回答冻结的参考敏感性问题；同一Dfam扩库命中再作为验证会循环论证。现有材料未提供足以将新增bp独立确证的证据，本轮不把有限抽样包装为基因组完整度估计，也不为得到阳性追加搜索。若未来要主张生物学漏注释，应另设匹配FP/TN、新FN及盲法正交验证；本次没有完成或宣称完成这项生物学验证。
4. **不改训练结果：** curated-only监督可能影响模型学习到的覆盖范围，这是后续可检验的解释。本实验只改变评价参考，未干预训练，不能将这一解释写成已证明的机制。Plant/Fungi、MoE扩展和新Gap搜索继续暂缓。
