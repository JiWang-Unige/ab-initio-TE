# Chicken native gene-utility result

The fixed chicken arm completed all ten 5-Mb cores (50,000,000 core bp;
52,000,000 bp including halos) on galGal6. The complete reference contains
1,064 protein-coding CDS-chain loci, and every core has all four paired arms
`U`, `D`, `R_TE`, and `RED`. No geometry, model parameter, mask threshold, or
reference locus was changed after prediction.

| arm | TP | FP | FN | precision | recall | F1 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| U | 280 | 916 | 784 | 0.234114 | 0.263158 | 0.247788 |
| D | 285 | 835 | 779 | 0.254464 | 0.267857 | 0.260989 |
| R_TE | 289 | 819 | 775 | 0.260830 | 0.271617 | 0.266114 |
| RED | 33 | 591 | 1,031 | 0.052885 | 0.031015 | 0.039100 |

The primary paired comparison D−U is +0.013201 F1, with chromosome-bootstrap
95% interval [0.005109, 0.025163]. D−R_TE is −0.005125 F1, with interval
[−0.010349, −0.001594]; the fixed historical TE mask is slightly better on
this chicken panel. D−RED is +0.221889 F1, with interval
[0.189399, 0.248788]. These intervals resample the ten fixed chromosomes and
are sensitivity intervals rather than biological-replicate uncertainty.

All four arms used the same 52,000,000-bp input (the 50-Mb core plus halos).
The lowercase material supplied to AUGUSTUS was 0 bp for U, 706,036 bp
(1.3578%) for D, 2,186,893 bp (4.2056%) for R_TE, and 34,412,248 bp
(66.1774%) for RED. RED was generated by native Red on this fixed 52-Mb panel;
it is an all-repeat mask and is not a full-genome Red run. Its high masked
fraction is consistent with the RED arm's very low gene recall and F1 and
supports overmasking as an explanation; it does not isolate the causal
contribution of masking from other differences between the arms. The D−RED
contrast is therefore a panel-specific masking-intensity control rather than
a claim of universal superiority.

## Coding-sequence overlap diagnostic

The existing masks were also intersected with the merged CDS union from the
complete protein-coding reference isoforms for each core. D masks 677,650
core bp and only 283 merged CDS bp (0.0139% of 2,034,021 CDS bp); R_TE masks
2,091,349 core bp and 1,192 CDS bp (0.0586%); RED masks 33,081,990 core bp
and 1,023,600 CDS bp (50.3240%). The full per-core diagnostic is in
`posthoc-mask-cds-diagnostic.json` and
`POSTHOC-MASK-CDS-DIAGNOSTIC.md`. This supports interpreting RED's low F1 as
an all-repeat overmask control on this fixed panel, but does not isolate the
causal contribution of masking.

This result supports a modest benefit of the learned D mask for native
AUGUSTUS relative to unmasked sequence and a large benefit relative to the
all-repeat RED mask. It does not establish superiority to a same-assembly
reference mask, and it is a D-training species rather than an unseen-species
generalization test. The complete machine-readable result is
`chicken/result.json`; scheduler and cell evidence remain in the experiment
status report.
