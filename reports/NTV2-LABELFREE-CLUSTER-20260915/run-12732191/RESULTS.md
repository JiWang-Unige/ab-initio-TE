# NTv2 无 family 标签适配：完成结果

2026-09-15，训练/评价12732191已完成（41分33秒），权重核查12733074已完成。实际更新原生encoder最后两层，但聚类收益并不一致；本轮不能声称适配稳定优于冻结NTv2或k-mer自监督基线。

## 评价资格

保留1331条自然拷贝记录，TRAIN/CAL/EVAL为806/266/259；对应独立split分组为725/240/240，共1205组。排除此前已查看的235个query和34个同50kb块记录；同源组、source-copy与50kb块跨split交集均为0。分组是防泄漏单位，不是生物TE insertion真值；同一人类assembly内的留出也不是物种泛化验证。

上游面板曾按已知family选样。因此“无标签”严格指本次正负对、loss、更新步数和K选择不使用family标签；不是从未注释基因组中完全无监督发现TE。40个family的EVAL标签仅用于外部聚类评价。K由冻结原始NTv2的TRAIN silhouette从预定20/30/40/50中选择，实际K=20，六臂相同；没有使用已知40个family直接设置K。

适配相对冻结NTv2的EVAL内ARI增加0.020603，但NMI减少0.003058；TRAIN拟合的聚类器应用于EVAL时，ARI减少0.004702。各项均是这个固定seed、固定面板的观察值，未给出显著性或跨物种优势。不同端点的排序不一致，不选择其中较好的一列作为整体提升。

容量匹配的具体对象是投影头：k-mer头为1,081,728参数，扩大后的冻结NTv2头为1,081,642参数；微调臂另含33,570,816个backbone可训练参数。因此，该对照没有匹配微调臂的总容量，不能声称已经完全隔离encoder更新的额外容量效应。所有臂共用的K来自raw NTv2 TRAIN选择，虽没有使用family标签，却不等同于对各表示中性的最优聚类搜索。这些限制不改变保存指标，也不授权依据EVAL新增训练。

## 是否真正更新了encoder

CPU核查直接将保存的layer27/28状态与原生safetensors按键和shape逐项对应，30个状态tensor全部匹配，其中28个权重tensor发生数值变化，两个rotary-frequency buffer保持不变，最大绝对差0.0046758130；配置记录33570816个可训练backbone参数。没有为核查重新训练。详见 `weight_update_audit.json`；保存状态还包括buffer，其总元素数不等同于可训练参数量。
