# Remote evidence inventory

This directory contains only compact summaries and the two small Phase 7
data-source scripts copied from Baobab.  It does not contain genome FASTA,
RepeatMasker BED archives, checkpoints, or credentials.

The authoritative machine-readable qualification is
`status.json`.  The source files are preserved with assembly names where the
remote directories had the same basename.  They support the conclusion that
natural annotated intervals and Dfam consensus material exist.  The initial
inventory alone did not close the source-copy/homology contract; the bounded
exact-repName panel builder later constructed coordinate-derived IDs and the
resulting retrieval outputs are reported under `../remote_runs/` and in
`../EXACT_HG38_REPORT.md`.  Those IDs still do not establish biological
insertion truth.
