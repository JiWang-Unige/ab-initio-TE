## 建议与依据

建议保留一个不同机制的候选：保持原始独立 4096-bp 两半输入与完整 H0
初始化，只比较损失在两个半段之间的归一化。暂不实施，先批准完整协议。
这是一个有明确对照、但目前因果依据有限的实验，不承诺能够改善 worm。

已核实的事实：

- [PAIR8 结果](CROSS-SPECIES-L1-PAIR-CONTEXT-V1.md)：工程验证与训练、
  评估均通过，但 worm SCREEN 对 BLOCK4 的 F1 增益仅 +0.003497；
  DEV 对 BLOCK4 为 −0.001610、对 D 为 −0.003412，且 F1=0.794154<0.8。
  因此 PAIR8 已关闭，不开展其 seed17、长度搜索或阈值补救。
- [既有 J0 汇总](CROSS-SPECIES-L1-NEXT-MECHANISM-20260908.md)：
  D 的 FN 以完全漏检与末端漏检为主；四个既有面板的单阈值 oracle
  F1 余量仅 0.000009–0.002048。这不支持把调阈值作为下一主路线，
  也不证明损失归一化就是漏检原因。
- [INIT 结果](CROSS-SPECIES-L1-INIT-HISTORY-V1.md)：P0R 未通过双参考
  比较与保护条件。初始化补救与该分支继续训练仍关闭。
- 当前 `scripts/experiments/CROSS-SPECIES-L1-20260903/cross_species_token_task.py`
  的 `bp_weighted_pair_loss` 确实先分别除以每半段的加权监督 bp 质量，
  再对两个半段求均值。没有证据表明这是实现错误；它体现半段等权的目标。

推断与未知：相同 bp 的隐含权重随其半段总监督质量变化。改成 tile 内
合并分母会改变训练目标，可能改善也可能损害召回、精度与 hardN。
它仍不是全数据集 pooled bp 风险：tile 和物种仍等权，而且正类权重仍为3。
因此不将候选称为“正确归一化”或“修复 bug”。当前没有新算出的质量
分布、相关性或因果证据；也不重复已有 D0 token ceiling、长度分层诊断。

## 唯一干预与匹配对照

令每半段加权 CE 分子为 A1、A2，监督质量 Mi=3×positive_bp+negative_bp。

| 项目 | HALF 控制 | TILE 候选 |
|---|---|---|
| tile 损失 | (A1/M1+A2/M2)/2 | (A1+A2)/(M1+M2) |
| 输入与注意力 | 原始独立两半，无跨半注意力 | 相同 |
| 初始化 | 原完整 H0，含原分类头 | 相同 |
| 其他训练与评估 | 原 D 合同 | 相同 |

两个公式在 M1=M2 时相同；否则候选按 Mi 分配两半贡献。不得再同时改变
TE 权重、tokenization、采样、mask、head 或 backbone。不得使用 PAIR8
训练权重初始化。BLOCK4、H0R 不是新的匹配控制的替代品：前者包含打包/
checkpointing 路径，后者重新初始化了分类头；原 D 保留为实际基线。

保留原 TRAIN：worm3000 tile、其他五物种各1500；每步每物种一个原 tile，
双臂相同采样流；六物种仍均匀平均。完整参数 AdamW、LR2e-5、wd0.01、
grad norm1、4000步/400 warmup、final checkpoint only。不按 DEV 漏检
富集 TRAIN，不改变 P>U>N、H、未知标签和 callable 语义。

## 拟议执行顺序与停止规则（均待批准）

1. 小型合成验证公式、梯度及数据不变性：等质量时两臂相同；不等质量时
   符合上述公式；未知/特殊/padding 不进入监督质量。零质量半段沿用原
   数据合同的报错，不擅自忽略、补零或重采样。
2. 仅用既有 TRAIN 做有界真实模型 smoke。核实双臂仅损失归一化不同，
   测量显存、完整六物种 step 与推理成本。若不能按完整合同装入已批准
   资源或总预算，则资源 STOP，不缩步数、物种或数据。
3. seed42 双臂匹配训练；完整日志、曝光量、配置通过后，每模型一次原
   global CAL 和注册 SCREEN/DEV。D 使用现存结果，不重新评估或选阈值。
4. seed42 必须通过下面所有条件，才可执行预先明确批准的 seed17。
   任一科学条件失败则关闭此损失实验，无同配方延训、权重搜索或替换 seed。

## 拟议科学门槛

这些是新协议的待批准决策标准，不追溯修改 PAIR8，也不是经验噪声界限。
保持 +0.005 最小效应，不因 PAIR8 接近某条门槛而下调。

- seed42：TILE 的 worm SCREEN、DEV F1 均须对 HALF 与同 seed D
  **分别增加至少0.005**，不平均掉任一失败面板。
- TILE 所有六物种 DEV 与 worm SCREEN：F1≥0.8，P/R≥0.75；
  macro DEV F1≥0.83。宏平均不能抵消弱物种失败。
- 对两参考分别维持 AP 损失≤0.002、各非 worm DEV F1 损失≤0.01；
  DEV/SCREEN segment F1@0.8 与 joint boundary F1@5 损失≤0.05；
  fragments/truth 与 split≤1.25×参考、missed rate 增加≤0.03；
  macro DEV hardN FP 增加≤0.005。零参考不加平滑。
- 条件 seed17：两个 worm 面板对两参考均严格正增益，且同样通过绝对
  readiness 与全部保护条件。无第二次 +0.005 要求，不挑选更好 seed。
- 两 seed 都通过仅产生内部候选；复用 DEV 不构成独立泛化证据。
  空间区间如获批准只作描述，不逆转门槛，也不代替 seed 重复。
