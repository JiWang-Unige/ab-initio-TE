# D 固定序列的上下文干预小实验

2026-09-17，依据作者本轮补充机制证据的要求，在运行前固定。目的是检验 D 是否使用窗口内的参考非 TE 上下文；不是为已有模拟 benchmark 的低 recall 预设解释。

## 固定设计

- 使用已经暴露的六物种 DEV 文件，不读取 CONF/封存物种，不训练或重新校准。每物种按源文件顺序选前32个合格且 tile_id 不重复的4096bp窗口，共192个。
- 合格：全部ACGT，至少256个参考TE碱基、256个普通参考BG碱基、64个距TE run边缘至少32bp的TE内部碱基，且至少128个BG碱基位于长度≥16的连续BG段。按标签和序列条件选取，不读模型分数。
- 三臂：原序列；仅普通BG段做保留首尾和二核苷酸计数的shuffle；仅TE段做同类shuffle作为序列特异性扰动。H（hard negative）和?保持不动。
- 每段shuffle使用随机化的Euler路径，固定seed42派生的局部RNG。不是所有可能序列的均匀抽样，也不是多训练seed。
- 使用既有冻结D checkpoint、原CAL Platt参数及阈值、4096窗口、原tokenizer/碱基投影，三臂具有相同坐标和长度。

主比较为BG-shuffle minus native在**完全不变的TE序列**上的平均P(TE)、固定阈值recall，以及内部TE子集的相同量；逐窗口配对、逐物种报告。另报告实际被改写的BG比例和hard-negative score/FPR，仅作干预描述，不把合成背景当独立验证的真实非TE。TE-shuffle臂改变了目标TE自身，原标签不再是有效生物真值，只报告原TE位置的分数与阈值阳性率，不称为准确率。

本批只检验D对配对干预的反应，不重跑传统工具，也不预设传统工具的结果必然不变。此第一阶段不改变训练或模拟生成器。一次运行完成后结束；小效应/无效应也报告，不搜新的扰动直到变阳性。

## 解释边界

若背景干预改变预测，只支持本模型对这种局部序列干预敏感；不能单独证明学习了进化机制、不是记忆、或完全解释GARLIC跨域下降。若影响主要集中边缘，更需考虑tokenization/边界效应。若TE自身打乱影响更大，支持局部序列模式使用，但仍不证明生物因果。

本批是已暴露DEV上的有限机制诊断，不是独立泛化评估。只有本批有可解释效应时，后续才讨论保持真实TE拷贝、长度、divergence、GC、位置和切片一致的native-context/transplant实验。

资源：1个Slurm GPU作业，4 CPU、32GB、最多1小时，无训练。脚本及逐窗口结果保留在同名实验目录，不覆盖原模型或benchmark。
