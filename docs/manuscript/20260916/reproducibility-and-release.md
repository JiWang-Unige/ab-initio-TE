## Reproducing the new compact diagnostic

From the repository root, `python3 scripts/experiments/SPECIES-LIBRARY-CONTROL-20260916/summarize.py` uses the standard library to reaggregate 1,500 tile rows, compare historical metrics and verify native counts, settings and version headers. The version text files are the first two lines of the native stdout logs; native summary-table copies have trailing whitespace removed. Full logs and annotations remain on Baobab. This local check does not rerun inference or recreate the original missing position cache.

`python3 scripts/experiments/SPECIES-LIBRARY-CONTROL-20260916/plot.py` requires Matplotlib and creates PDF, SVG and PNG from the qualified compact JSON. The figure was generated with Matplotlib 3.11.2. The native `diagnostic.py` and Slurm entry points document the actual inference/annotation route and require the research inputs and runtime; running those stages is not needed to reproduce the compact metrics.

The count/prevalence plot is generated by `scripts/experiments/plot_species_annotation_diagnostic_20260916.py`; the benchmark and Tiberius plots by `scripts/experiments/plot_manuscript_closure_20260916.py`; the conceptual overview by `scripts/experiments/plot_study_overview_20260916.py`. Each uses the linked results, not newly selected models. Omni reproduces aggregate benchmark scores from compact block statistics, not the native annotation calls.

## Availability boundary and remaining submission preparation

Protocols, execution scripts, compact metrics, failure ledgers and figure sources are in the existing GitHub repository. Source assembly identifiers, library releases and runtime details are retained in the study-specific protocols and acquisition/qualification records. D, P3, source-model, SF5 and representation checkpoints are distinct; no single downloadable checkpoint currently reproduces all manuscript results.

Full genomes, exported reference libraries, model weights, position arrays and native whole-genome outputs remain in the research workspace. The present push does not redistribute them. A complete public release still needs selected checkpoint artifacts with their original calibration and supported inference path, upstream weight/data redistribution terms, source acquisition instructions, and a versioned release location. No DOI or release artifact has been created or claimed.

The scientific working text and current result figures include the completed finite experiments and their negative findings. Author/affiliation/contribution details, a complete journal-formatted bibliography, final supplementary layouts and release packaging remain before submission. These are disclosed preparation tasks; they do not justify automatically opening the sealed evaluation panels, adding training seeds, or launching new Gap, MoE, plant or fungal experiments.
