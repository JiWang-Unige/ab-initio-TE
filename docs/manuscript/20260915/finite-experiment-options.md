# 有限补实验方案：围绕论文主张选择

2026-09-15，Codex 设计草案。依据 [已核实结果](verified-status.md)，不把所有支线都列为投稿前必须完成。具体数据范围、预算和选择规则尚未冻结；此文件不提交作业，不修改已有结果。

## 优先包 A：可信的比较基线与误差来源

**目的：回答 GLM 在什么条件下提供额外的 TE 识别价值，而不是只比较和某一张注释表的一致率。**

1. 选注释来源可追溯的锚点和外部挑战面板。人/小鼠可提供较完整的基因组资源，但仍须说明 TE 标签的证据来源；外部物种应先满足阳性与背景资格。标签不合格时先解决资格，不以低 reference coverage 当成模型失败。
2. 公平运行现有三条传统路线：固定 library RepeatMasker、RepeatModeler2→RepeatMasker、HiTE，以及固定 GLM。需要全基因组重复拷贝支撑的 de novo 方法应在合适规模建库，然后在共同评价区域评分。区分可用参考库与无目标参考库场景；不能给某个方法评估用整理库而忽略这一知识优势。
3. 合格阳性面板只支持 reference-positive recall；未知背景不能全部当作生物真阴性。若报告 precision/F1，必须有相应独立核实的负例/未标注区域抽样，并说明抽样范围、未决状态与需要的分层权重。按方法分歧抽样和随机背景抽样分开，避免只核实本模型喜好的候选。
4. 固定 assembly 与 RepeatMasker 版本，比较旧/新 library；独立地核实边界邻接和孤立候选。这样区分 library 改变带来的评分变化、真实补注释与模型仍未识别的 TE。跨 assembly 对应只有在序列资格成立时用于对应证据。
5. L1 碱基材料、L2 annotation-component 拓扑、L3 生物插入身份分别评分；没有 L3 真值时明确 N/A。模拟可用于插入结构压力测试，真实整理用于生物有效性；不能合并成一个“真实全基因组准确率”。
6. 记录全部失败/超时及资源。完整建库、后处理、特征计算、模型 forward 的成本分项报告；冷启动和缓存复用分开。已有 1 MiB CPU/GPU probe 保留为局部测速，不冒充端到端排名。

**收敛条件：** 得到同任务、同坐标、分母合格的比较结果和参考敏感性分解后即可写结果。GLM 没有全面胜出也是有效结果；不要通过更换已见 EVAL、删除超时或扩预算为单个方法补胜局。更换方法或协议形成新批次，保留原矩阵。

## 条件包 B：下游效用若要成为主要应用贡献

先利用既有输出核实 16 个 P/R 共同损失 loci，以及 NOD2、DCC、MALT1、CCNF、TIGD7 五个相异 loci：检查输入 mask、预测链、参考转录本及基因重叠的 TE 证据，记录仍未确定的机制。这个解释性分析不需要新的模型训练。

若继续声称普遍应用，再在未用于调参、且下游预测器适用的外部物种/区域做新协议比较。固定配置的 unmasked 与 softmask 工作流应各用适合的 checkpoint；P3 与共享 D 不混为同一注释器。比较全流程的功能作用时，使用实际原生 RepeatMasker mask，明确 TE-only 与 all-repeats 的语义差异。

**主要结果同时包含平均效用、P 对 R 的效应区间，以及原正确位点损失。** 若未来目标变成部署风险控制，预设该任务可接受的损失，不事后放宽当前 1% 门。无跨物种验证时只写人类固定面板的输入干预结果；增加小鼠也不能直接覆盖所有动物。

## 条件包 C：分类若要保留为独立贡献

先明确目标为粗类别、具体 superfamily，还是已知 family 的检索。固定层级映射，把 ambiguous、known-other、unclassified 与未标注背景分开记录。修复验证集评分遗漏，并记录 checkpoint 是按哪个实际验证集选择的。

在完整、坐标可追溯的六物种评价上报告物种等权及类别支持，既有 480 窗口结果只作历史诊断。若新增人类/小鼠锚点，独立区分数据选择、训练、验证及最终评价；有“未见 family”主张时按同源组隔离，而不是只随机切窗口。GLM 预训练来源与下游监督划分分别披露；held-out 坐标不自动意味着预训练未见。

**收敛条件：** 独立区域/拷贝和稀有类支持足以估计预设效应后停止，不以固定窗口总数代替样本量理由。若仅保留粗类别补充结果，可收窄主张，无需为本篇论文立即扩展一个精细分类器。

## 可选支线 D：真正无监督的可训练 NTv2

四个有限对照：强 k-mer、冻结 NTv2、冻结 NTv2+无标签投影、可训练 NTv2+相同无标签目标。保持数据、可见信息、评价与选择规则一致；公平性不是把所有表示的维度机械设成相同。

类别标签不能参与训练对、阈值/K/超参选择；冻结后才用于外部聚类评价。保留自然 copy 的同源隔离和物种分层，评估聚类合并、碎裂及未见类。不要把监督 retrieval top1 换名为无监督 clustering；不要把 projection-only training 换名为 backbone fine-tuning。

Pro 审阅进一步建议保留原始强基线，并增加头容量对照，以区分 encoder 更新与单纯增加参数；它提出的六臂/2000 updates 仍是候选方案，尚未据实际资源和数据冻结。若序列通过 TE 注释筛选，准确表述为 TE-enriched、family-label-free 学习。归纳式簇分配与在未标注 EVAL 上进行的转导式聚类分开报告。

**收敛条件：** 只回答一个预先确定的比较问题。若强 k-mer 仍更好，报告该结果，停止为“GLM 必须胜出”继续搜索。固定单 seed42，仍按独立区域/拷贝等单位给出不确定性。此支线可以形成后续工作，不必拖住当前主线。

## 暂不扩展

- 不因平均 bp 分数小幅变化继续扩大 MoE；已有保留性与结构损失仍是反证。
- 不继续救同一 Gap 阈值/decoder 冻结问题。真实 fragment linking 是另一项研究，只有在获得可靠 insertion identity 真值、能识别错误合并时才值得启动。
- 不把 multi-prototype retrieval 自动扩展成已被证实的 multi-reference annotation 优势。
- 不为论文“显得完整”同时增加转录调控、植物大面板、多个新 GLM 和多 seed。它们各自需要独立问题、数据与验证。

建议主论文先选 A；若以实际使用为卖点，再选 B。C/D 是否进入主要贡献，决定是否在本篇完成。相关论文与期刊的范围对照见 [来源记录](source-notes.md)。
